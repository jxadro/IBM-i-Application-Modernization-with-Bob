Etapa 2 — Gestión de Artículos

Catálogo de artículos, precios (venta y stock), stock actual y mínimo, familia, código IVA y relación con proveedores. Arquitectura de servicio FARTICLE con módulos RPGLE reutilizables.

Reglas de Negocio

BR-ART-001  CONFIRMADA
Código de artículo único (ARID, 6 chars)
Clave primaria de ARTICLE. Unicidad garantizada por fichero físico. Duplicado → error de clave.
BR-ART-002  CONFIRMADA
Precios positivos (ARSALEPR y ARWHSPR)
ART202 valida que ARSALEPR > 0 y ARWHSPR > 0 antes de escribir el registro.
BR-ART-003  REGLA_NO_CONFIRMADA
Stock mínimo ≤ stock actual (ARMINQTY ≤ ARSTOCK)
Regla deducida del diseño de campos. No confirmada en código fuente actual.
BR-ART-004  CONFIRMADA
Familia (ARTIFA) debe existir en FAMILLY
ART202 verifica la familia usando GetArtFam(). Registros huérfanos no permitidos.
BR-ART-005  CONFIRMADA
Código IVA (ARVATCD) referencia VATDEF. Default='2'
ExistVATRate(VATCODE) valida el código IVA. SAMREF.PF define DFT('2') para VATCODE.
BR-ART-006  CONFIRMADA
Baja lógica via ARDEL='X'
No hay borrado físico. IsArtDeleted(ARID) verifica ARDEL. Artículos con ARDEL='X' no pueden pedirse.

Programas IBM i

ART200 .PGM.SQLRPGLE
Programa principal de lista de artículos con subfichero. Accede a ARTICLE2 (LF por familia) y ARTICLE1. Usa /copy familly para las funciones de familia. Llama a ART201 para gestión de proveedores.
ART202 .PGM.RPGLE
Mantenimiento completo del artículo: todos los campos de ARTICLE. Valida familia, precios e IVA. Aplica patrón panel/step (prp/lod/dsp/key/chk/act).
ART201 .PGM.RPGLE
Gestión de relación artículo-proveedor (ARTIPROV). Referenciado como extpgm('ART201') con parámetro ARID.
ART300 .RPGLE (módulo FARTICLE)
Módulo de servicio: funciones CRUD de artículo sobre ARTICLE1. Exporta todas las funciones GetArt* e IsArtDeleted.
ART301 / ART302 .SQLRPGLE (módulos)
ART301: funciones SQL de artículo (SltArticle, GetArtInfo). ART302: validaciones adicionales con SQL embebido.
ART400 .SQLRPGLE
Módulo de reporting de artículos. Genera datos para informes de stock y valoración via ARTLSTDAT view.

API del Servicio FARTICLE — Funciones Exportadas

GetArtRefSalPrice(ARID)→ PACKED 7,2 — Precio de venta
GetArtStockPrice(ARID)→ PACKED 7,2 — Precio de stock
GetArtFam(ARID)→ CHAR 3 — Código de familia
GetArtStock(ARID)→ PACKED 5,0 — Stock actual
GetArtMinStock(ARID)→ PACKED 5,0 — Stock mínimo
GetArtVatCode(ARID)→ CHAR 1 — Código IVA
ExistArt(ARID)→ N — ¿Existe el artículo?
IsArtDeleted(ARID)→ N — ¿Está dado de baja?
SltArticle(ARID)→ CHAR 6 — Selección interactiva
GetArtInfo(ARID)→ CHAR 1520 — Info completa serializad
