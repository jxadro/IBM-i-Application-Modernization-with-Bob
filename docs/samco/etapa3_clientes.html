Etapa 3 — Gestión de Clientes

Alta y mantenimiento de clientes con numeración automática (CUSSEQ), validación de país, gestión de crédito y acceso directo al historial de pedidos. Servicio FCUSTOMER.

Reglas de Negocio

Flujo de integración: CUS200 (lista) → CUS301 (mantenimiento/alta). Desde CUS200, opción 5 abre ORD200 con el cliente filtrado.
BR-CUS-001  CONFIRMADA
Número de cliente autogenerado por secuencia SQL CUSSEQ
CUS200/CUS301 consume el siguiente valor de CUSSEQ (QSQLSRC/CUSSEQ.SQLSEQ) para asignar CUID al nuevo cliente.
BR-CUS-002  CONFIRMADA
País del cliente (CUCOUN) debe existir en COUNTRY
CUS200 usa /copy qprotosrc/country. CUS301 valida el código de 2 chars contra COUNTRY.COID.
BR-CUS-003  CONFIRMADA
Crédito disponible = CULIMCRE – CUCREDIT
CULIMCRE es el límite autorizado; CUCREDIT el saldo utilizado. La diferencia determina si se puede crear un nuevo pedido. Expuesto via GetCusLimCredit() y GetCusCredit().
BR-CUS-004  CONFIRMADA
Baja lógica via CUDEL='X'
IsCusDeleted(CUID) verifica el campo CUDEL. Los clientes dados de baja no pueden crear pedidos.
BR-CUS-005  CONFIRMADA
CULASTORD actualizado automáticamente por trigger ORD701
Ningún programa de clientes actualiza CULASTORD. El trigger SQL ORD701 (AFTER INSERT ORDER) lo hace automáticamente con ordate del nuevo pedido.

Programas IBM i

CUS200 .PGM.SQLRPGLE
Programa principal de lista de clientes con subfichero. Accede a CUSTOME2 (LF por país) y CUSTOME1 (LF por nombre). Importa prototipos de COUNTRY via /copy qprotosrc/country. Llama a ORD200 para pedidos del cliente.
CUS301 .SQLRPGLE
Mantenimiento completo de cliente. Gestiona: número de cliente (CUSSEQ), todos los campos de contacto y dirección, país (con validación), límite de crédito y estado. SQL embebido para operaciones sobre CUSTOMER.
CUS300 .RPGLE (módulo FCUSTOMER)
Módulo de servicio del programa FCUSTOMER. Exporta todas las funciones GetCus* / ExistCus / IsCusDeleted / sltcustomer / CloseCUSTOME1.

API del Servicio FCUSTOMER

GetCusName(CUID)→ CHAR 30 — Nombre del cliente
GetCusPhone(CUID)→ CHAR 15 — Teléfono
GetCusMail(CUID)→ CHAR 50 — Email
GetCusCountry(CUID)→ CHAR 2 — Código de país
GetCusLimCredit(CUID)→ PACKED 9,2 — Límite de crédito
GetCusCredit(CUID)→ PACKED 9,2 — Crédito utilizado
ExistCus(CUID)→ N — ¿Existe el cliente?
IsCusDeleted(CUID)→ N — ¿Está dado de baja?
sltcustomer(CUID)→ PACKED 5,0 — Selección interactiva
CloseCUSTOME1()Cierra el cursor del fichero
