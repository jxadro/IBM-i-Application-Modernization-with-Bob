Reglas de Negocio

BR-PRO-001  CONFIRMADA
Número de proveedor único (PRID, 5 dígitos packed)
PRID es la clave primaria de PROVIDER. Unicidad garantizada por el fichero físico.
BR-PRO-002  CONFIRMADA
Precio proveedor (APIPRI) independiente del precio de venta
ARTIPROV.APIPRI almacena el precio de compra del proveedor, sin relación con ARTICLE.ARSALEPR. Relación M:N entre artículos y proveedores.
BR-PRO-003  CONFIRMADA
Baja lógica via PRDEL='X'
Proveedores no se eliminan físicamente. PRDEL referenciado en SAMREF como DLCODE.

Programas IBM i

PRO200 .RPGLE
Lista de proveedores con subfichero. Accede a PROVIDE1 (LF por nombre). Llama a PRO202/PRO203 para mantenimiento.
PRO202 .SQLRPGLE
Mantenimiento de datos del proveedor con SQL embebido: nombre, contacto, dirección, VAT, email, país.
PRO203 .PGM.SQLRPGLE
Detalle del proveedor y gestión de artículos asignados (ARTIPROV). Permite añadir/modificar relaciones artículo-proveedor con APIPRI.
PRO300 .RPGLE (módulo FPROVIDER)
Módulo de servicio del programa FPROVIDER. Exporta funciones de acceso a PROVIDER.

Familias de Artículos (FAMILLY)

BR-MAE-001  CONFIRMADA
Código familia (FAID) de 3 caracteres, único
FAMILLY declara UNIQUE. FAM300/FAM301 gestionan el ciclo de vida de familias.
BR-MAE-002  CONFIRMADA
Tasa IVA por familia (FAVATCD) referencia VATDEF
FAVATCD es el código IVA por defecto que hereda el artículo al asignarse a la familia. CLCVat() lo usa para el cálculo en pedidos.
BR-MAE-004  CONFIRMADA
Baja lógica en familias via FADEL='X'
No se eliminan familias con artículos activos. FADEL marca la baja lógica.

Países, Parámetros e IVA

BR-MAE-003  CONFIRMADA
Código país (COID) de 2 chars, ISO-3166
COUNTRY tiene campos adicionales COISO (alpha-3), COISO5, COISO1 para variantes. COU300/COU301 gestionan el maestro.
API del Servicio FVAT
GetVATRate(VATCODE)→ PACKED 4,2 — Tasa %
GetVATDesc(VATCODE)→ CHAR 20 — Descripción
ExistVATRate(VATCODE)→ N — ¿Existe?
CLCVat(VATCODE, NetValue)→ PACKED 9,2 — Importe IVA

Programas IBM i

FAM300 / FAM301 .RPGLE
FAM300: módulo de servicio FFAMILLY. FAM301: pantalla de mantenimiento de familias vía FAM301D.DSPF. Valida código IVA con ExistVATRate().
COU300 / COU301 .RPGLE
COU300: lista de países (COU200D). COU301: mantenimiento (COU301D). Módulo FCOUNTRY provee GetCountry* functions.
PAR200 / PAR300 .RPGLE
PAR200: pantalla de mantenimiento de parámetros (PAR200D). PAR300: módulo de servicio FPARAMETER para lectura de parámetros.
PAR201 .CLLE
Programa CL de procesamiento batch de parámetros. Crea/actualiza parámetros en la tabla PARAMETER desde jobs planificados.

Log de Aplicación

BR-UTL-001  CONFIRMADA
Log: usuario + timestamp + mensaje (≤500 chars)
LOG300.AddLogEntry() construye la entrada: "User: X * Date: TS * Msg: M ***". Se escribe en user space SAMLOG.
BR-UTL-002  CONFIRMADA
Log en user space SAMLOG (*LIBL)
LOG300 usa API IBM i RTVUSRSPCPTR sobre 'SAMLOG *LIBL'. Escritura en posición incremental (pos += len(data2)).

Fechas, Texto y XML

DAT001 / DAT002 .RPGLE
Utilidades de fecha para conversión y manipulación de fechas IBM i. DAT002 especializado en conversiones de formato.
ISOTODATE / ISOTODATE4 .SQLUDF
UDFs SQL en QSQLSRC para convertir fechas ISO a formato DATE de Db2. ISOTODATE4 maneja años de 4 dígitos.
TXT001 .RPGLE (módulo TXT)
Utilidades de procesamiento de texto: cadenas, padding, limpieza. Exportado como servicio TXT en SAMPLE.BNDDIR.
XML001 .RPGLE (módulo XML)
Generación y parseo de XML para intercambio de datos con sistemas externos. Integración con IFS para leer/escribir stream files.

Programas de Log

LOG300 .RPGLE (módulo LOG)
Módulo de servicio del srvpgm LOG. Usa XREF SAMLOG *USRSPC. Función AddLogEntry(entry: CHAR 500). Inicialización lazy via flag 'inz'.
LOG100 .PGM.RPGLE
Visor y mantenimiento del log de aplicación. Permite consultar las entradas de SAMLOG desde la interfaz 5250.

Objetos SQL y Arquitectura

ART801 .SQLPRC — Stored Procedure
Procedimiento almacenado SQL para procesamiento de artículos. Puede invocarse desde aplicaciones web/REST o batch.
ORDERCUS .VIEW — Vista SQL
JOIN consolidado de ORDER + CUSTOMER. Expone todos los campos de pedido con datos del cliente para informes y REST APIs.
ORD701 .SQLTRG — Trigger SQL
AFTER INSERT ON ORDER: actualiza CULASTORD en CUSTOMER. Único punto de actualización automática de fecha de último pedido.
